## 📖 Sobre

Este projeto reúne e organiza minha trajetória de estudos, cursos e certificações em um único ambiente web.

Os dados são mantidos em uma planilha do **Google Sheets** e processados automaticamente por um script em **Python**, executado no **Google Colab**, que gera uma página HTML atualizada para publicação no **GitHub Pages**.

O objetivo é centralizar a gestão do conhecimento, facilitar o acompanhamento da evolução profissional e demonstrar uma abordagem orientada por dados e automação.

---
